# All View

All View is a Windows file previewer. Select a file in File Explorer and press **Space** to preview it. Press **Escape** to close the preview.

- Preview documents, images, text, media and other supported formats.
- Search documents and recognize text in scanned pages and images.
- Browse nearby files and inspect folder contents.
- Capture screenshots, edit images and print previews.

Files stay on your computer. Previews leave the original files unchanged.
